# 05｜行业语言适配器

优先从目标机会的官方描述、学科写作规范、读者习惯提取词汇；不得只因行业名称类似就照搬话术。

| 目标与读者 | 前置信号 | 可用语汇与表达重点 | 避免 |
|---|---|---|---|
| 临床导师/住培/医学学生 | 真实临床接触、研究训练、可靠沟通、学习能力 | 病例观察、证据评价、临床问题、研究设计、患者教育 | 把观摩写成独立诊疗、把课题设计写成临床验证 |
| 学术科研/实验室 | 研究问题、方法、成果、共同作者贡献 | 研究假设、样本/方法、数据、分析、报告、发表 | 无证据称论文发表、独立主持及显著性 |
| 软件工程 | 系统设计、具体贡献、质量与维护 | 架构、实现、测试、性能、可复现性、部署 | 将整个仓库视作个人独立编码；无意义工具罗列 |
| 产品经理/交互 | 用户问题、定义、取舍、迭代与影响 | 用户研究、目标、需求拆解、原型、交付、反馈 | 只有漂亮 UI 无产品结果；宣称无法验证增长 |
| 设计/内容/品牌 | 作品、策略、表达判断、受众效果 | 视觉叙事、信息架构、设计系统、作品链接 | 只谈审美不谈受众、版权与个人贡献 |
| 财务/咨询 | 分析能力、商业判断、执行、沟通 | 估算、模型、尽调、流程、决策支持、业务结果 | 模糊的“具有商业思维”，捏造收益贡献 |
| 教育/教学 | 教学对象、方法、课程资源、反馈 | 教学设计、差异化辅导、学习材料、课堂体验 | 没有证据的“学习效果提高X%” |
| 公共部门/非营利 | 服务对象、规则、可追责的组织贡献 | 项目协调、资源统筹、服务设计、公共沟通 | 无关的活动人数、夸大社会影响 |
| 法律/政策 | 逻辑、检索、写作、准确表达 | 案例检索、论证、文件审阅、问题界定 | 冒称法律代理权限或案件裁判成果 |
| 营销/运营 | 受众、渠道、活动执行、可核查结果 | 内容规划、转化、触达、协作、洞察 | 粉丝/曝光与有效转化混为一谈 |
| 设计研究/UX | 研究设计、证据、需求发现、验证 | 定性访谈、任务流、原型、可用性、迭代 | “对用户体验大幅改善”而没有证据 |
| 创业/独立创作者 | 从问题到可交付产品的全链条 | 用户需求、产品定义、验证、制作、发布、迭代 | “商业化成功”但没有实际收款或市场证据 |

同一经历可写多个目标版本，例如医学3D图谱：
- **临床导师版**：强调空间解剖理解和教学使用；
- **产品版**：强调从三维学习困难到交互原型的需求定义与设计；
- **工程版**：若有代码证据再强调3D引擎、剖切机制、渲染性能。

不要把行业词当装饰。每个词要匹配具体经历。

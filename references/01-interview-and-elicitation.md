# 01｜自然语言访谈与素材挖掘

## 不用长问卷的六层追问

围绕已经出现的故事，根据缺失字段逐层追问；同轮最多1–2个高价值问题。

| 层 | 判别与问法 | 可得到的可写内容 |
|---|---|---|
| 情境 S | “当时遇到什么具体困难/机会？为什么值得做？” | 项目价值与背景 |
| 职责 R | “你负责哪一部分？哪些是和别人共同完成的？” | 职位、职责边界 |
| 决策 D | “你亲自决定/推动了哪一步？有什么取舍？” | 主导力、判断力 |
| 行动 A | “你做了什么实际动作？可以给一段例子吗？” | 动词与可观察活动 |
| 产物 O | “最后交出了什么？有链接、文档、证书、复盘吗？” | 成果与证明入口 |
| 反思 G | “哪一点最能体现你愿意被怎样认识？” | 个人品质与长期方向 |

## 第0轮：极简、受众优先

一个自然段说明：我会先整理材料，不要求你按模板叙述。只问“这份简历给谁看，用来争取什么？”及“对方看完最希望记住你的哪两项优势？不确定可由我先提议。”允许略过第二题。

如是求职、学术、导师、项目申请，分别说明阅读对象和机器投递渠道可能不同。

## 第1轮：开放式素材回忆

鼓励用户上传已存在的：旧简历、项目README、证书、作品链接、课程报告、活动照片、工作证明、演讲、录音转文字；只读取经授权材料。先提炼再追问。

不要求用户按顺序回答。一个强追问通常是：“讲一件你最投入、但简历没讲清楚的经历。为什么做、你做了什么、最后留下什么？”

## 第2轮：针对资料缺口的高收益追问

- 只写“参与科研”：追问“你实际负责研究问题、查文献、数据、实验、写作还是协调？哪个环节最可追问？”
- 只写“组织活动”：追问“你决定/协调了什么，活动如何实际进行？有没有独立负责的内容？”
- 只写“产品优秀”：追问“用户最能看到的三个功能或体验是什么？是否有可打开的作品？”
- 只写“沟通能力强”：追问“一次怎样把复杂信息讲清楚、帮助谁理解？”
- 只有数字（如21份样本）：追问“这个数字对收件人说明了什么？若无意义，提炼组织与方法，而不是强行突出数字。”
- 项目含自己/团队/AI角色：追问“哪些问题是你提出并做决策的，哪些工作由团队或 Agent 执行？”
- 专业词密集：追问“没有这三个术语，对方是否还看得懂重要性？”

## 默认不问

不要无必要索取身份证号、出生日期、完整家庭住址、宗教、婚育状况、敏感医疗信息、同学患者隐私。照片仅当用途、地区或用户要求后再讨论；允许“不要照片”。

## 每轮小结格式

“我已经获得：①……②……。最可能打动目标读者的是……。还差一个关键事实：……？”不要把全量待补材料清单逐条逼用户回答。

## 用户说“我不知道”的替代

Agent 根据已知材料提出2个合理的候选优点或策略，明确它们只是编辑假设；让用户选择、否定或用自己语言修改。用户可以继续下一阶段，不必直到所有资料齐备。

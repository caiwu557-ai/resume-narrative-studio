# 11｜十二种结构预设及其选择准则

所有结构处理同一份已批准的数据，视觉主题的数量不作为质量指标。比较时先固定同一份履历和同一套中性颜色、字体、阅读节奏，确认结构区别，再讨论配色与气质。下列方向有共同的可读性保护线，不再提供高密度/紧凑模板。

| 结构 ID | 构图与阅读机制 | 合适内容 | 慎用情形 |
|---|---|---|---|
| `ats-clean` 清晰单栏 | 姓名→信息→标题→经历连续顺序，简明规则线，无复杂布局 | 自动投递/普适最保守稿 | 不用作夸张作品集；依官方格式另做DOCX |
| `formal-split` 横向身份区 | 上方姓名/联系信息左右分区，正文单栏 | 医疗、管理、一般导师 | 联系信息过长时折行，不缩字 |
| `research-ledger` 学术索引 | 左侧章节定位，右侧完整经历叙述；章节级横向分组 | 长期学术CV、科研叙述 | 长章节标题、非常长的每节，需复核栏宽和分页 |
| `ivory-classic` 象牙书信 | 居中身份、左右对称线、正文左起，强调文书礼仪和留白 | 教育、人文、正式场合 | 高强度即时岗位扫描时用更直接单栏 |
| `book-editorial` 书卷编辑 | 大幅姓名，与右侧简介建立两块编辑层次；章节页的编号叙事 | 有清晰专业定位、重视文字的人 | 不把AI写的广告口号塞入简介 |
| `studio-grid` 工作室网格 | 等宽模块网格，长块跨两栏，短块配对，孤余短块自动跨栏 | 多种长度不同、可独立阅读的作品/经历 | 不适合连续长篇或需严格ATS顺序；自动长文降级需告知 |
| `product-feature` 核心作品 | 已确认的一个关键项目整栏突出，其他履历仍连续；项目元信息独立 | 有可展示的核心产品或案例 | 没有用户确认的 `featured:true` 时不生成虚假重点 |
| `portfolio-rail` 作品集侧栏 | 左侧身份/联系/简介，右侧完整经历主线 | 创意、个人作品展示 | 多页或复杂长联系信息需改用顺序正文；普通ATS不要用 |
| `experience-index` 经历索引 | 章节标题整栏，每条经历的真实日期或角色独立窄栏，正文右排 | 多项任职与项目快速对比 | 不是虚构时间线；日期或角色缺失则不强行编造 |
| `bold-poster` 大字海报 | 高对比整栏身份色块、大字姓名、横向色带与清晰编号 | 年轻创意岗位、设计展示 | 重色块占打印墨量；正式机器投递单独生成标准稿 |
| `pop-blocks` 青年拼贴 | 两色身份分区+横向简介带，5:3近似非等宽模块与整栏混合，轻量标签 | 内容、品牌、新媒体、年轻团队 | 不把每个段落都变成彩色框；信息量高应重排/续页 |
| `two-track` 双轨档案 | 完整页首，证据主轨和明确批准的支持信息侧轨 | 跨学科、科研和产品 | 只在用户确认 `placement:"support"` 时移动内容；两轨阅读顺序和多页重新审核 |

## 旧 16 个风格的处置

- ATS 纯文本保留；高密度ATS删除，不另起“经历多”变体。
- 研究简报、深灰高管、临床正式、科技工程与公共服务不再使用行业名来掩饰结构重复：可在横向身份区、学术索引、经历索引中选真正需要的结构，再选独立配色和字体；旧公共服务模板退役。
- 书卷编辑、象牙纸保留设计理念并重建；杂志目录合并入书卷编辑及大字海报，不再单靠换配色、改标题。
- 工作室网格和产品体系拆清设计任务：前者负责对等独立模块，后者负责一个经批准的重点项目；作品集侧栏独立保留，另设双轨档案（支持信息与主履历分栏，不等同左侧身份栏）。
- 新增更加大胆的大字海报、青年拼贴，但不因此免除正文规范或语境判断。

## 内容与布局选择

不要为了展示复杂网格而劈开一个需要连续理解的经历，也不要把短技能信息排成大段文字。优先让长叙述占主栏/整栏，短信息承载侧栏或模块。样例中的 `featured`、`placement`、`span` 是内容编排授权，不是默认凭空选择荣誉或项目。跨度守则：相邻两个短模块可以并排；若后面是跨栏、或奇数模块末尾落单，自动跨栏，不留无功能的半行。`long-form` 根据文本长度与章节数采取保守安全回退；实际页数仍由真实渲染决定。

## 自由混搭与约束

`templates/design_tokens.json` 是唯一权威：12 结构、12 角色化配色、7 字体组合、3 阅读节奏，A4 与 Letter 两个纸张。颜色是视觉角色（paper/ink/muted/accent/panel/band/band_ink/highlight/highlight_ink/line），不是随机RGB集合；文字配色搭配逐对测试。字体组分别指定标题/正文字族、字重和回退。用本机已有授权字体，不分发字体文件；部分西文字体在纯中文简历中会趋同。字体选择后应实际检查字面大小与换行，不能只根据名称认定差别。

混搭顺序：读者与渠道 → 结构 → 视觉配色 → 字体组合 → 阅读节奏 → 确认纸张 → 真实导出与验收。ATS基线锁定中性配色和通用字体；任何“换成鲜艳配色或展示体”的意愿转为真人版。用户可以自由选择人类阅读视觉版各项令牌，但组合并非无条件质量通过；改变参数后重新渲染、查页数、查溢出。

## 保留用户选择

先提供3个互有区别的候选（稳妥、结构上不同、较大胆），用同一数据对照；说明结构的功能区分。打开 `style-gallery.html` 后可选择预设、实时混搭及导出配置和当前HTML；用 `scripts/build_gallery.py` 为自己的已批准JSON重新创建Gallery，不要求将私人数据上传到网站。

# 17｜扩展个性化：在恰当阶段识别，而非开局全问

以下是可选分支，不是固定问题表。先读材料，识别触发信号，再自动采用可逆默认；用户明确指示优先于模型猜测，但真实资格、明确投递规范和隐私边界不能取消。所有决定使用 `personalization_contract.json` 记录范围。

| 触发 | 阶段／识别方式 | 默认应对与何时询问 |
|---|---|---|
| 用户给多个岗位/不同导师 | 0–3，目标要求显著不同 | 维护母版+定向版本；共用事实不共用排序，若无法确定第一目标才问优先级 |
| 目标读者有官方表格/字数/页数 | 0，读取JD/院校要求 | 强制格式优先；与自定义设计冲突，保留另一真人版。不能宣称不遵守也兼容 |
| 行业资格、执照、签证、在读/毕业 | 1–2，需准确日期/状态 | 只写证据支持的状态；实质资格未知时问一次，非必要敏感信息省略 |
| 转行、间隔期、非典型学习或兼职 | 1–3，按时间轴发现 | 用真实可迁移贡献和角色；不造解释、不擅自暴露家庭/疾病原因；必要时请用户选是否解释 |
| 初学者、没有工作经历 | 1–3 | 优先从课程项目、实验、志愿、个人作品寻找真实能力；缺证据也不造成功故事 |
| 资深/论文很多/长项目列表 | 4 | 代表经历放前，完整CV/发表清单或证据附录另交；不压字或随意删论文 |
| 自我介绍需不同语气 | 3–5 | 区分客观摘要、研究兴趣、个人陈述；简历精炼，个人陈述按要求独立；不重复正文 |
| 双语/外语/英文名 | 0,5,6 | 询问投递语言仅在未知且关键时；按官方译名和日期格式；中文与英文稿分别编辑，不直译口号；语言能力不猜等级 |
| 照片、头像不同用途、个人照片隐私 | 0,4,6 | 参考12，使用者明确选定原图才嵌入；缺照不留空；机器版省略 |
| 公开链接、私人作品或保密项目 | 1,4,7 | 不泄漏私有源；真实无链接等价于文字说明；公开链接核实；必要时用脱敏附录，不假装开放 |
| 用户审美参考图/学校或机构品牌色 | 4,6 | 提取结构/色彩/风格特征，非原样照搬；不能未经许可用商标；用户只换色则布局锁定 |
| 用户喜欢图标、照片、鲜艳、年轻 | 6 | 依据目标渠道分流，推荐12/13/14；预设之外可生成可审查角色色和真实布局 |
| 无障碍、大字、打印黑白 | 0,6,7 | 可见文字、对比度≥4.5、字号节奏large、稳定读序；不要依颜色图标传达唯一含义 |
| 用户要求文案夸张或“完美人设” | 5,7 | 提炼真实稀缺价值，不能虚构；不用在对外稿反复自我否定；内部审事实 |
| 学术学生奖项/共同工作 | 1,5 | 明确官方名称和贡献，不混淆参与与获奖、协作与主导、观察与实际操作 |
| 高风险覆盖、发送、公开上传、自动安装 | 7或任何阶段 | 说明风险及可逆替代；得到明确授权才执行。当前工作新建版本不覆盖 |
| 要 editable Word、PDF、HTML、纯文本 | 0,6 | 核心数据同源、各载体实渲染；平台无法产出则诚实给支持格式，不假装实现 |
| 用户时间很紧或希望少参与 | 0 | 自动推进/快速档；保留真实与披露确认；其余采用可逆默认，不问长表 |
| 用户说只是换个配色/改一个标题 | 任意 | 局部精修，锁内容和未改元素，重渲染必要部分，不重复访谈 |

## 触发优先级
强制条件 / 对外风险 → 事实 → 用户明确锁定 → 经推断偏好 → Agent默认。若用户的两项指令冲突（要求单页且全部经历不可删），提出取舍而不擅自缩字，交付可逆候选。任何自述都不推断敏感属性作为视觉、岗位或能力评价的依据。

# 21｜能力索引检索、学术申请与证据型编辑

## 检索不止于旧简历与姓名
先列目标读者需判断的 3–5 个能力信号，再按信号建立搜索地图。身份/正式记录→经历原始载体（课程分工、志愿记录、实验报告、会议通知、海报、课件）→实际可访问项目（README、版本、设计、源码/运行结果）→缺口回访。读上下文、表格/图像及署名归属；记录来源、访问范围、实际查看内容、日期、冲突与未索引范围。旧简历只能证明以前如何写，不能独立证明经历。检索不到不等于不存在；不猜链接，不把仓库存在、团队产物或 README 描述直接当个人独立成果或运行验证。

沿用 02 的证据层级，并增加 source_kind（原件、用户确认、自述、团队记录、历史稿、计划/模板）、inspection_scope（全文/部分/README/未访问）、contribution、stage、conflicts、next_verification。正式证据与用户确认可以支持不同强度的事实；用户确认不等于官方认证。冲突的日期、头衔、奖级先定位原件；仍未解则保留待核，使用不误导的较宽表达或省略，不自行选最新聊天。未经授权不访问项目、外发私人材料或搬运第三方资料。

## 对标与选材
用户/目标机构提供的真实范例，优先作为**信息结构**的场景证据；机构硬要求优先于审美。拆解读者入口、身份/时间/角色位置、方法与成果的关系、扫描顺序和有效密度。形成「借鉴机制—不复制资历—适用条件—具体改动」。范例不是录取效果的证据，不复制资历、指标、版式瑕疵。历史研究来源标明是否重新查阅。

对每个经历分为核心、强化、差异化、素材库存档，排序取决于当前读者，不以公开性为门槛。私有原型有实际证据和本人贡献就可陈述；不附私链或猜链接、不标开源。公开作品先写名称与读者能理解的用途，再按用户要求显示完整 URL 或短链接。核验可访问性与项目对应关系，PDF URI/DOCX relationship 仅证明链接嵌入，不能证明站点可达或功能已验证。

## 医学/学术导师申请适配器（仅在匹配场景启用）
| 信号 | 内容组织 | 防错边界 |
|---|---|---|
| 学业 | 学籍、培养类型、成绩、排名 | 排名口径/成绩来源；不堆日常学习习惯 |
| 临床/基层 | 机构、时间、见习或服务身份、行动 | 观摩/协助不等于独立诊疗；活动独立归属 |
| 科研 | 项目类型→阶段和角色→正式题名→实际方法/贡献→已形成的材料 | 计划分析不是完成建模；立项不是论文/验证；正式题名不得擅改 |
| 实验 | 训练背景、真实操作、报告和数据分析 | 课程实验不是该研究的产出；可同节独立子项 |
| 科普/会议 | 真实课件/活动名、角色及具体贡献 | 制作课件不等于主讲；参会不等于报告 |
| 医学教育/数字项目 | 学习问题、作用、真实功能、个人角色 | 不因未公开删除，不写无证据行业领先 |
| 任职/荣誉 | 正式职位、职责相邻、奖名/等级 | 同级强调一致；不以无关数字凑证据 |

可按实际目标合并科研和实验，但保留子项边界；中文正式题名按原文及用户确认标点写，如 `研究课题：《……》`。不把未来发展限定为当前研究项目。上述章节是候选而非强制模板，经验丰富申请者可能需要论文、独立科研、临床轮转等其他栏目。企业/ATS 场景不得套用医学标题、照片或全URL要求。

## 示例（虚构）
「某课题 已立项 · 学生负责人」→正式题名→组织文献整理、制定病例标准与数据字典，形成研究方案；拟采用回归与校准分析。另列「基础实验训练」完成课程中的操作与报告。此处无需写出“没有论文、没有建模”等否认性审计句；用状态动词保留实质边界即可。凡读者追问具体方法、角色、已有成果，应能回指事实总账。

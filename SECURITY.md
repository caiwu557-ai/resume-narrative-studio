# Security and privacy

Resume Narrative Studio renders user-supplied text and optional local images. Its generated HTML and sample galleries must be treated as **untrusted artifacts** when opened with unknown input.

- Never publish actual users' resumes, contact information, private notes, scanned certificates, medical data or API keys in this repository.
- Use dummy personal details in bug reports and examples.
- Inspect rendered HTML and linked assets before sharing publicly.
- Do not upload private source files to GitHub Pages.
- Use GitHub's private vulnerability reporting feature if available; otherwise contact the project maintainer privately. **Do not post secrets or personal data in public issues.**

A static code scan and sample tests are not a security certification. Independent review is welcome.

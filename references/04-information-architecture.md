# 04｜信息架构：章节结构从目标生长

## 不存在适用于所有人的“标准九章/十章”

首先识别文档类别，再定章节。标题的作用是**让读者立即知道下一部分包含什么**，不是展示文案功力。对于有10个主题但仅2页的文稿，常常应合并成5–7个大类；用户明确要求十节则保持十节，但统一页内逻辑和视觉层级。

## 四种基础架构（根据个案调整）

### A. 早期学生 / 导师联系（通常1页，丰富时2页）

姓名/身份与联系方式 → 学业基础 → 相关科研/临床观察 → 代表性项目 → 技能/服务 → 荣誉 → 研究方向（需要时）。重点决定“哪一项最能证明与导师方向相关”。

### B. 学术 CV / 科研申请（页数由资历决定）

教育与任职 → 研究领域 → 研究项目/方法训练 → 论文/报告/会议（必须真实区分角色） → 教学与服务 → 奖励与资助 → 技能/参考人。遵守学科和所在国要求。

### C. 企业与技术岗位（1–2页）

身份/联系方式 → 高度定制化摘要（有实际价值才放） → 相关项目/工作经历 → 技术或职业能力 → 教育/奖项。没有充分工作经验时可让相关项目先于其他次要材料。

### D. 创意/产品/公开作品（1–2页简历 + 作品集）

身份/核心能力 → 2–4个标志性案例（问题/本人行动/成果） → 工作/教育 → 技术与协作 → 作品入口。视觉版允许图、链接和少量图标；机器版仍单列。

## 章节命名原则

- 用大类称谓（“个人开发项目”“研究经历”“临床实践”“开源作品”“荣誉奖励”），避免项目级细节充当总标题。
- 有实质上不同的内容才拆节：如“学术交流”和“校园组织”不是同一类别；如果页面不够可把任职并入“其他履历/领导力”。
- 职业定位与未来目标若表达同一意愿，只保留一处；如两处确实有功能区分，开头写**现在已有的身份/优势**，结尾写**未来要争取的具体发展**。
- 不把第二页写成独立的宣传封面。页眉、章节序号、边距、字体系统与行文语气延续第一页。
- 图标和编号不是必须。有益则用；ATS 简历通常禁用装饰。

## 排序协议

1. 收件人关注事项：与目标职位/导师/项目直接相关的经验最先。
2. 证据强度与辨识度：可演示作品、关键角色和认可度高的荣誉优先。
3. 职业阶段：学生常先教育，资深员工常先经验；并非铁律。
4. 每个栏目内部，默认倒序时间；若采用精选项目顺序，应标为“代表性项目”，避免误读时间序列。
5. 收尾：向未来发出具体而克制的行动方向，不用重复的空泛口号。

## 两页连续性检查

为第一页定义“身份/资格/核心证明”，第二页定义“补充证明/工作方式/奖励与期望”。将第一页末一节和第二页首一节连读，若主题跳跃，调整先后或共用一个上位标题体系。

## 页面空间合同

- 根据文本量和字号设计，不追求空白率数字；页与页正文区域的**视觉密度应接近**。
- 段落前后间距优先保证阅读节奏；不靠删行距/缩字号来塞版。
- 避免页首长标题后仅剩一行、栏目标题与正文分离、孤行、链接从上下文断开。
- 图片/头像占用空间必须有充分用途；作品集可另页展示多图，不把毕业求职简历变成宣传海报。
- 版面留白是信息组织工具。底部大片空白且上方拥挤是分配问题；底部自然留白并非自动失败。

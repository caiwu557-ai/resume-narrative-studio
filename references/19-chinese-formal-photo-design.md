# 19｜中国大陆正式简历头像安置：人类审查→场景策略→可运行验收

## 一、命题裁决

**用户提交的12款头像审计基本成立。** 审计中的“优选/合理/有条件合理/不推荐”是针对**中国大陆、面向真人阅读、用户或投递方确有附照片需求的正式简历**的设计判断。它不代表某国强制规定，更不表示任何居中照片在所有场合都违规。

证据与边界：
- 湖南第一师范学院《2024届毕业生就业指南》明确描述照片一般放在简历右上角、个人信息右侧。这是一个真实的国内高校实践建议，**不能推广成中国就业的统一国家标准**。https://sim.hnfnu.edu.cn/info/1066/2622.htm
- NN/g 的 Gestalt Proximity（接近原则）说明空间接近促成信息分组；Visual Hierarchy 解释字号、色彩、留白对注意力分配的影响；这些并未专门比较右上照片的招聘效果。https://www.nngroup.com/articles/gestalt-proximity/ ; https://www.nngroup.com/articles/visual-hierarchy-ux-definition/
- UC San Diego Career Center 说明 ATS 更适合简单结构，避免列、照片和图形；Princeton 也建议其美国简历不加照片。https://career.ucsd.edu/resources/guides/resume.html ; https://careerdevelopment.princeton.edu/resume-guide/basic-principles-resume-writing

## 二、策略顺序与人类决策

先问答或从 brief 判断：对谁、什么地区、是否要求/允许照片、是否 ATS、用户是否明确批准当前用途的照片。缺信息时**不从中文、用户姓名、照片外貌推断国籍或申请地区**。

严格顺序：
1. 投递方官方强制格式 > 用户已经批准的布局与用途 > 适配的场景默认 > 模板自身艺术构图。
2. ATS 模式无头像。图片存于另行授权的真人版，不偷偷加入机器稿。
3. 对 `cn-formal` 真人版，**只有已获用户准许且有照片输入时**才启用照片；默认采用 **A. 页眉右上独立式**。
4. `formal-split / studio-grid / product-feature / two-track` 可以选择 **B. 页眉三栏式**，但须额外检查长联系方式、长姓名与照片间的碰撞。
5. `creative`/作品集模式允许将头像放在姓名上方、左侧栏或色块内，**不会因正式版推荐而删除艺术版**。
6. 用户明确坚持非标准人像位置时，提供可视化对比，说明风险并保留其选择；不得擅自覆盖已锁定的设计决定。
7. 无头像时，不保留空框和多余留白。续页不重复头像；有头像的姓名依然比照片具有更重要的视觉层级。

## 四、真正的视觉规范（不只位置）

- 头像应在第一页页眉身份组内，靠近姓名与身份，但不得侵入科研、教育、作品等正文内容。
- 默认裁切起点 26×32mm，仅是程序的空间参数，不冒充法律规定的证件照尺寸；根据实际简历、照片质量可调整。
- **姓名视觉优先级高于头像**：不要把头像尺寸放大到成为文案阅读的入口，尤其避免独立超大色块。
- A 型布局：`header` 形成相对定位的身份区，头像右上锚点，左侧姓名/身份/联系方式共享剩余宽度。不能仅使用 `float:right` 再任其覆盖文字。
- B 型布局：`minmax(0,1.13fr) / minmax(0,.87fr) / 26mm` 三个列区域，分别承载身份、联系方式、头像；移动端改用纵向排布，打印须额外验收。
- 姓名过长、国际邮箱或两行联系方式造成碰撞时，优先扩大身份区、改A式、换页、调整信息结构；绝不通过缩小正文解决。
- 将正式/创意版风格模式作为**可逆**选择，不破坏原模板预设颜色、字体与正文布局。正式版的头像布局规范优先于极端视觉装饰，必要时建议切换更适合的原生正式模板。

## 五、实际Agent交互（最多一个关键问题）

- 已知目标为国内甲乳外科导师、用户明确说“使用这张照片” → 直接选择 `audience_profile=cn-formal`、`photo_mode=auto`，默认右上，不重复追问。
- 目标是创意作品集、用户喜欢象牙书信居中头像 → 采用 `audience_profile=creative`，保留原设计。
- 不确定国家或投递渠道，用户只上传图片 → 不自动发布/嵌入，必要时问“这张照片是给哪份简历用的？”
- 国内正式版，用户特别喜欢三栏 → 在适用的四款模板中选 `photo_mode=three-column`，给缩略图与右上独立式比较。
- 用户不想放照片 → `photo_mode=none`，删掉占位框。

## 六、可执行入口与自动检查

- `templates/photo_policy.json`：场景规范、每个主题原始位置、正式优选程度、支持的替代。
- `scripts/personalization.py`：`select_photo_mode` / `photo_recommendation`。用户输入 `cn-formal` 由 Agent 的 brief 判断，不能从语言或姓名推断。
- `scripts/render_resume.py`：`--audience-profile cn-formal` + `--photo-mode auto|header-right|three-column|editorial|none`。旧 v1.2 参数和默认创意排版继续兼容。
- `tests/test_photo_policy_v13.py`：12款规则与实际视觉坐标检查、长联系方式、移动端/打印、ATS 去图、无照回退、创意兼容。

## 七、失败例与反例

**失败例**：生硬把书卷编辑的照片全部移动到右上，却保留原来窄左栏和强行居中姓名的排版；身份信息失去关联，页面变坏。修复需同步调整页眉信息结构、保留整页风格连续性。

**反例**：个人品牌作品集首页突出人物照片，甚至整张人物半身像，合理且可能强化作者识别度；但这是独立介绍页的设计策略，不能推广到学术导师简历。

**适用边界**：这一套面向含照片的中文正式简历；国际学术CV、不同地区规范、教师资格/考试专用表格和官方固定报名模板，应服从收件方的具体要求。
